# 🏆 Gerenciador de Campeonato

Projeto em desenvolvimento de um sistema para gerenciamento de campeonatos, com foco em organização de times, partidas, tabela de classificação e estatísticas automáticas.

---

## 📌 Sobre o projeto

Este sistema tem como objetivo facilitar a criação e gestão de campeonatos esportivos, permitindo cadastrar times, gerar confrontos automaticamente e acompanhar o desempenho ao longo da competição.

O projeto ainda está em desenvolvimento e novas funcionalidades estão sendo adicionadas continuamente.

---

## ⚙️ Funcionalidades

### ✅ Em desenvolvimento / já implementadas
- Cadastro de times
- Listagem de times
- Geração dinâmica de lista com JavaScript

### 🚧 Em desenvolvimento
- Sorteio automático de confrontos entre os times
- Sistema de tabela de classificação
- Registro de partidas e resultados
- Cálculo automático de pontos

### 📊 Futuras funcionalidades
- Estatísticas individuais e por time
- Gols marcados e sofridos
- Aproveitamento (%) dos times
- Interface mais interativa e responsiva
- Salvamento de dados (LocalStorage ou backend)

---

## 🧠 Tecnologias utilizadas

- HTML5

## 🏅 Funcionalidades principais (visão do sistema)

- 🧩 Cadastro de equipes
